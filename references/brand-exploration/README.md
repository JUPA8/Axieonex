## How to review

Open these three pages in a browser (in this order):

1. `Axieonex Brand Exploration.dc.html` — brand strategy, critique of the current mark,
   and the four concepts with full lockup systems, monochrome variants and small-size tests.
2. `Axieonex Comparison Board.dc.html` — all four concepts under identical conditions
   (web, product, social, print), platform specs, and the 1–10 scoring matrix + recommendation.
3. `Axieonex Website Directions.dc.html` — one website visual-direction preview per concept.

Each concept folder contains: `symbol.svg`, `symbol-mono-black.svg`, `symbol-mono-white.svg`,
`symbol-favicon-32.svg`, `wordmark.svg`, `lockup-horizontal.svg`,
`lockup-horizontal-tagline.svg`, `lockup-horizontal-white.svg`, `lockup-horizontal-black.svg`,
`lockup-stacked.svg`, and `NOTES.txt`.

SVGs are clean geometry: real paths only, no embedded rasters, no filters, no gradients,
and every mark holds in a single solid colour. Wordmark type is live `<text>` for review;
outline it before production.

Transparent PNG previews: SVG is resolution-independent and is the master format — export
PNGs at the exact sizes you need (400×400, 1024×1024, 512×512) from the SVGs once a
direction is approved, so we are not shipping raster files for a mark that may still change.
