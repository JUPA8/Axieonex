# Reference-only and superseded files

Everything listed here is preserved for historical context. Claude Code must **not** implement any of it as a canonical page, asset, or style source. The canonical files live in `prototype/`, `styles/`, `scripts/`, `manifests/`, `motion/`, and `docs/`.

## Superseded design drafts

- `Axieonex Homepage.dc.html (V1)` — early homepage draft, replaced entirely by `prototype/Axieonex Homepage V2 - Revenue in Motion.dc.html`.
- `Axieonex Brand Exploration.dc.html` — Phase 1 brand-strategy exploration deck (four early logo concepts, before the approved AXIEONEX X mark existed).
- `Axieonex Comparison Board.dc.html` — comparison board for those four early concepts.
- `Axieonex Website Directions.dc.html` — early website-direction previews for those same concepts.
- `SymbolA.dc.html`, `SymbolB.dc.html`, `SymbolC.dc.html`, `SymbolD.dc.html` — the four early concept symbols (Twin Apex, Convergence, Compound, Open Quadrant). None of these is the approved mark; the approved mark is `LogoMark.dc.html` (also present in `assets/` and `prototype/`).
- `brand-exploration/` folder — full Phase 1 exploration output (per-concept SVGs, strategy notes). Reference only.

## Uploaded reference images

- `uploads/` folder — user-supplied historical logo and material references, including images whose wordmark is misspelled **AXIONEX**. This spelling must never be reproduced anywhere in the implementation. The correct name is always **AXIEONEX**. These images may only be used as visual/material inspiration (metallic surface, lighting, geometry) exactly as already interpreted into the approved `LogoMark` and page-specific themes; do not embed the raster images themselves and do not trace their wordmark.

## Why these are excluded

Every file above predates or was replaced by the approved, currently-live design system documented in `manifests/Axieonex Implementation Manifest.md`. Treating any of them as a build source would reintroduce an abandoned direction, an incorrect brand spelling, or content that was never part of the shipped design.
